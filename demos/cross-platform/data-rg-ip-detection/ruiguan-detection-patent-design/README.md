# Ruiguan Detection Patent Design API

Detect design-patent risks by comparing a product image with patent records across more than 25 jurisdictions.

[Official API documentation](https://www.nexscope.ai/api-docs/ruiguan-detection-patent-design?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/ruiguan-detection-patent-design.json)

[Repository API reference](../../../../docs/data/ruiguan-detection-patent-design.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-rg-ip-detection/ruiguan-detection-patent-design
node demos/clients/node/run.mjs demos/cross-platform/data-rg-ip-detection/ruiguan-detection-patent-design
java demos/clients/java/Run.java demos/cross-platform/data-rg-ip-detection/ruiguan-detection-patent-design
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/ruiguan-detection-patent-design/run`.
