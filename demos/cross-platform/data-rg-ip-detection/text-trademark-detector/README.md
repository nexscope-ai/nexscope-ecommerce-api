# Text Trademark Detector API

Detect text-trademark and infringement risks in ecommerce product listings.

[Official API documentation](https://www.nexscope.ai/api-docs/text-trademark-detector?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/text-trademark-detector.json)

[Repository API reference](../../../../docs/data/text-trademark-detector.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-rg-ip-detection/text-trademark-detector
node demos/clients/node/run.mjs demos/cross-platform/data-rg-ip-detection/text-trademark-detector
java demos/clients/java/Run.java demos/cross-platform/data-rg-ip-detection/text-trademark-detector
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/text-trademark-detector/run`.
