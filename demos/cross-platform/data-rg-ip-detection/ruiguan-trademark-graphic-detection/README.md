# Ruiguan Trademark Graphic Detection API

Find visual matches between product images and registered graphic trademarks.

[Official API documentation](https://www.nexscope.ai/api-docs/ruiguan-trademark-graphic-detection?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/ruiguan-trademark-graphic-detection.json)

[Repository API reference](../../../../docs/data/ruiguan-trademark-graphic-detection.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-rg-ip-detection/ruiguan-trademark-graphic-detection
node demos/clients/node/run.mjs demos/cross-platform/data-rg-ip-detection/ruiguan-trademark-graphic-detection
java demos/clients/java/Run.java demos/cross-platform/data-rg-ip-detection/ruiguan-trademark-graphic-detection
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/ruiguan-trademark-graphic-detection/run`.
