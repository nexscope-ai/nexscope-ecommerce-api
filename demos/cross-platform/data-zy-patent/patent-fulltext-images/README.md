# Patent Fulltext Images API

Retrieve drawings, diagrams, and charts from patent documents by patent ID or publication number.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-fulltext-images?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-fulltext-images.json)

[Repository API reference](../../../../docs/data/patent-fulltext-images.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-fulltext-images
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-fulltext-images
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-fulltext-images
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-fulltext-images/run`.
