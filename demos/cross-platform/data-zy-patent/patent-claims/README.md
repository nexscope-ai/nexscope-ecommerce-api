# Patent Claims API

Read a patent's claims to understand what the patent covers.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-claims?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-claims.json)

[Repository API reference](../../../../docs/data/patent-claims.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-claims
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-claims
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-claims
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-claims/run`.
