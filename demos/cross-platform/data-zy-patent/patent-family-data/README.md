# Patent Family Data API

Find related patent filings across countries and patent offices.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-family-data?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-family-data.json)

[Repository API reference](../../../../docs/data/patent-family-data.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-family-data
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-family-data
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-family-data
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-family-data/run`.
