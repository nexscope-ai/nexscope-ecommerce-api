# Patent Title Abstract Translation API

Read translated patent titles and abstracts. Call the Patent Title Abstract Translation API via REST or MCP with your Nexscope API key.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-title-abstract-translation?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-title-abstract-translation.json)

[Repository API reference](../../../../docs/data/patent-title-abstract-translation.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-title-abstract-translation
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-title-abstract-translation
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-title-abstract-translation
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-title-abstract-translation/run`.
