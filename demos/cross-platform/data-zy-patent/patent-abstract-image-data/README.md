# Patent Abstract Image Data API

View patent abstract drawings by patent ID or publication number.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-abstract-image-data?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-abstract-image-data.json)

[Repository API reference](../../../../docs/data/patent-abstract-image-data.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-abstract-image-data
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-abstract-image-data
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-abstract-image-data
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-abstract-image-data/run`.
