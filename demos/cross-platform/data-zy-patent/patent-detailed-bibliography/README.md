# Patent Detailed Bibliography API

Look up a patent's publication details, applicants, and inventors.

[Official API documentation](https://www.nexscope.ai/api-docs/patent-detailed-bibliography?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/patent-detailed-bibliography.json)

[Repository API reference](../../../../docs/data/patent-detailed-bibliography.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/patent-detailed-bibliography
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/patent-detailed-bibliography
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/patent-detailed-bibliography
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/patent-detailed-bibliography/run`.
