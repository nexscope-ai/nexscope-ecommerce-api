# Zhihuiya Patent Image Search API

Find visually similar design patents from an image URL with country, legal-status, date, Locarno-classification, and assignee.

[Official API documentation](https://www.nexscope.ai/api-docs/zhihuiya-patent-image-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/zhihuiya-patent-image-search.json)

[Repository API reference](../../../../docs/data/zhihuiya-patent-image-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-zy-patent/zhihuiya-patent-image-search
node demos/clients/node/run.mjs demos/cross-platform/data-zy-patent/zhihuiya-patent-image-search
java demos/clients/java/Run.java demos/cross-platform/data-zy-patent/zhihuiya-patent-image-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/zhihuiya-patent-image-search/run`.
