# Product TRO Detection API

Screen product images for potential intellectual property risks, including temporary restraining orders (TROs).

[Official API documentation](https://www.nexscope.ai/api-docs/maidalv-product-tro-detection?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/maidalv-product-tro-detection.json)

[Repository API reference](../../../../docs/data/maidalv-product-tro-detection.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/cross-platform/data-md-product-tro-detection/maidalv-product-tro-detection
node demos/clients/node/run.mjs demos/cross-platform/data-md-product-tro-detection/maidalv-product-tro-detection
java demos/clients/java/Run.java demos/cross-platform/data-md-product-tro-detection/maidalv-product-tro-detection
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/maidalv-product-tro-detection/run`.
