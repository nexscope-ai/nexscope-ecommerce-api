# Shopee Product Search API

Search and filter products across supported Shopee markets in Asia and Latin America for product selection and marketplace.

[Official API documentation](https://www.nexscope.ai/api-docs/shopee-product-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/shopee-product-search.json)

[Repository API reference](../../../../docs/data/shopee-product-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/shopee/data-shopee-product-selection/shopee-product-search
node demos/clients/node/run.mjs demos/shopee/data-shopee-product-selection/shopee-product-search
java demos/clients/java/Run.java demos/shopee/data-shopee-product-selection/shopee-product-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/shopee-product-search/run`.
