# TikTok Video Rankings API

Rank TikTok videos by available performance measures to identify content worth reviewing for product and creator research.

[Official API documentation](https://www.nexscope.ai/api-docs/data-kd-video-rank?co-from=github-ecommerce-api) · [Request payload](../../../../demos/tiktok/data-kd-tiktok/data-kd-video-rank/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-kd-tiktok/data-kd-video-rank
node demos/clients/node/run.mjs demos/tiktok/data-kd-tiktok/data-kd-video-rank
java demos/clients/java/Run.java demos/tiktok/data-kd-tiktok/data-kd-video-rank
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
