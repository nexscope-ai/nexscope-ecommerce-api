# TikTok Product Analytics Detail API

Review a TikTok product's price, sales, revenue, commission, and shop details.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-product-analytics-api?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-product-analytics-api.json)

[Repository API reference](../../../../docs/data/tiktok-product-analytics-api.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-kd-tiktok/tiktok-product-analytics-api
node demos/clients/node/run.mjs demos/tiktok/data-kd-tiktok/tiktok-product-analytics-api
java demos/clients/java/Run.java demos/tiktok/data-kd-tiktok/tiktok-product-analytics-api
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-product-analytics-api/run`.
