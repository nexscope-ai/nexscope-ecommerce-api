# TikTok Video Analytics API

Compare TikTok promotional videos by views, engagement, and sales revenue.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-video-analytics?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-video-analytics.json)

[Repository API reference](../../../../docs/data/tiktok-video-analytics.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-kd-tiktok/tiktok-video-analytics
node demos/clients/node/run.mjs demos/tiktok/data-kd-tiktok/tiktok-video-analytics
java demos/clients/java/Run.java demos/tiktok/data-kd-tiktok/tiktok-video-analytics
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-video-analytics/run`.
