# TikTok Video Download URL API

Resolve TikTok video URLs to playback, cover-image, watermarked, and no-watermark download addresses for offline analysis.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-video-download-url?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-video-download-url.json)

[Repository API reference](../../../../docs/data/tiktok-video-download-url.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-et-tiktok/tiktok-video-download-url
node demos/clients/node/run.mjs demos/tiktok/data-et-tiktok/tiktok-video-download-url
java demos/clients/java/Run.java demos/tiktok/data-et-tiktok/tiktok-video-download-url
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-video-download-url/run`.
