# TikTok Seller Detail API

Review a TikTok seller's sales, followers, ratings, products, and promotional content.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-seller-detail?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-seller-detail.json)

[Repository API reference](../../../../docs/data/tiktok-seller-detail.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-et-tiktok/tiktok-seller-detail
node demos/clients/node/run.mjs demos/tiktok/data-et-tiktok/tiktok-seller-detail
java demos/clients/java/Run.java demos/tiktok/data-et-tiktok/tiktok-seller-detail
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-seller-detail/run`.
