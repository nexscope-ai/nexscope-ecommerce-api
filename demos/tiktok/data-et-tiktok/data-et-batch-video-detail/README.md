# TikTok Video Details in Bulk API

Retrieve details for several TikTok videos in one request to compare their content and available performance information.

[Official API documentation](https://www.nexscope.ai/api-docs/data-et-batch-video-detail?co-from=github-ecommerce-api) · [Request payload](../../../../demos/tiktok/data-et-tiktok/data-et-batch-video-detail/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-et-tiktok/data-et-batch-video-detail
node demos/clients/node/run.mjs demos/tiktok/data-et-tiktok/data-et-batch-video-detail
java demos/clients/java/Run.java demos/tiktok/data-et-tiktok/data-et-batch-video-detail
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
