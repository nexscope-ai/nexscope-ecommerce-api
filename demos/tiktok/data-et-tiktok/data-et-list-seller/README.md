# TikTok Seller Search API

Find TikTok sellers by region and available sorting options to research shops and identify relevant competitors.

[Official API documentation](https://www.nexscope.ai/api-docs/data-et-list-seller?co-from=github-ecommerce-api) · [Request payload](../../../../demos/tiktok/data-et-tiktok/data-et-list-seller/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-et-tiktok/data-et-list-seller
node demos/clients/node/run.mjs demos/tiktok/data-et-tiktok/data-et-list-seller
java demos/clients/java/Run.java demos/tiktok/data-et-tiktok/data-et-list-seller
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
