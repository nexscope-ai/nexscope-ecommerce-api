# TikTok New Product Rank API

Discover trending new products across 16 TikTok Shop markets using regional new-product ranking data.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-new-product-rank?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-new-product-rank.json)

[Repository API reference](../../../../docs/data/tiktok-new-product-rank.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-et-tiktok/tiktok-new-product-rank
node demos/clients/node/run.mjs demos/tiktok/data-et-tiktok/tiktok-new-product-rank
java demos/clients/java/Run.java demos/tiktok/data-et-tiktok/tiktok-new-product-rank
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-new-product-rank/run`.
