# TikTok Shop Product Detail API

Retrieve public TikTok Shop product details by supported region.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-shop-product-detail?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-shop-product-detail.json)

[Repository API reference](../../../../docs/data/tiktok-shop-product-detail.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-tiktok-shop-product-detail/tiktok-shop-product-detail
node demos/clients/node/run.mjs demos/tiktok/data-tiktok-shop-product-detail/tiktok-shop-product-detail
java demos/clients/java/Run.java demos/tiktok/data-tiktok-shop-product-detail/tiktok-shop-product-detail
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-shop-product-detail/run`.
