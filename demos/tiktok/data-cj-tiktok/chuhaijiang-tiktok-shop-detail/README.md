# TikTok Shop Detail API

Look up a TikTok shop to research a competing seller.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-shop-detail?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-shop-detail.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-shop-detail.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-detail
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-detail
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-detail
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-shop-detail/run`.
