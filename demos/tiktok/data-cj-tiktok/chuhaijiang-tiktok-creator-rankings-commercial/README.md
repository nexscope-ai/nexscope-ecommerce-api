# TikTok Creator Commercial API

Find TikTok creators ranked by commercial performance.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-creator-rankings-commercial?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-creator-rankings-commercial.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-creator-rankings-commercial.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-rankings-commercial
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-rankings-commercial
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-rankings-commercial
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-creator-rankings-commercial/run`.
