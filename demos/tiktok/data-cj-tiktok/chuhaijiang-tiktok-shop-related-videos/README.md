# TikTok Shop Related Videos API

Find videos featuring products from a TikTok shop.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-shop-related-videos?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-shop-related-videos.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-shop-related-videos.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-related-videos
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-related-videos
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-shop-related-videos
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-shop-related-videos/run`.
