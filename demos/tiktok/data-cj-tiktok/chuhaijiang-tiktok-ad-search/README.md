# TikTok Ad Search API

Search TikTok ads for competitor and creative research.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-ad-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-ad-search.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-ad-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-search
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-search
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-ad-search/run`.
