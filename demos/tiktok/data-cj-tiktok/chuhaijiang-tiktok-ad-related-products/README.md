# TikTok Ad Related Products API

Find products featured in a TikTok ad. Call the TikTok Ad Related Products API via REST or MCP with your Nexscope API key.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-ad-related-products?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-ad-related-products.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-ad-related-products.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-related-products
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-related-products
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-ad-related-products
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-ad-related-products/run`.
