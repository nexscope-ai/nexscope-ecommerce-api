# TikTok Creator Related Lives API

Find livestreams associated with a TikTok creator.

[Official API documentation](https://www.nexscope.ai/api-docs/chuhaijiang-tiktok-creator-related-lives?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/chuhaijiang-tiktok-creator-related-lives.json)

[Repository API reference](../../../../docs/data/chuhaijiang-tiktok-creator-related-lives.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-related-lives
node demos/clients/node/run.mjs demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-related-lives
java demos/clients/java/Run.java demos/tiktok/data-cj-tiktok/chuhaijiang-tiktok-creator-related-lives
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/chuhaijiang-tiktok-creator-related-lives/run`.
