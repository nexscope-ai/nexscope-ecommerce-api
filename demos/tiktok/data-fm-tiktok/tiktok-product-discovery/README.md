# TikTok Product Discovery API

Search and filter global TikTok Shop products by keyword, category, shop type, commission, sales, creator count, and sorting.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-product-discovery?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-product-discovery.json)

[Repository API reference](../../../../docs/data/tiktok-product-discovery.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-fm-tiktok/tiktok-product-discovery
node demos/clients/node/run.mjs demos/tiktok/data-fm-tiktok/tiktok-product-discovery
java demos/clients/java/Run.java demos/tiktok/data-fm-tiktok/tiktok-product-discovery
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-product-discovery/run`.
