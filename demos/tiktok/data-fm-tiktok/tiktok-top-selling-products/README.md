# TikTok Top Selling Products API

Query TikTok Shop top-selling product rankings by day, week, month, market, and category.

[Official API documentation](https://www.nexscope.ai/api-docs/tiktok-top-selling-products?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/tiktok-top-selling-products.json)

[Repository API reference](../../../../docs/data/tiktok-top-selling-products.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/tiktok/data-fm-tiktok/tiktok-top-selling-products
node demos/clients/node/run.mjs demos/tiktok/data-fm-tiktok/tiktok-top-selling-products
java demos/clients/java/Run.java demos/tiktok/data-fm-tiktok/tiktok-top-selling-products
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/tiktok-top-selling-products/run`.
