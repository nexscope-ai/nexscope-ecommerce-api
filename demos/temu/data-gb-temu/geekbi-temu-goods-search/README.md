# GeekBI Temu Product Search API

Search Temu products for competitor and assortment research.

[Official API documentation](https://www.nexscope.ai/api-docs/geekbi-temu-goods-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/geekbi-temu-goods-search.json)

[Repository API reference](../../../../docs/data/geekbi-temu-goods-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/temu/data-gb-temu/geekbi-temu-goods-search
node demos/clients/node/run.mjs demos/temu/data-gb-temu/geekbi-temu-goods-search
java demos/clients/java/Run.java demos/temu/data-gb-temu/geekbi-temu-goods-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/geekbi-temu-goods-search/run`.
