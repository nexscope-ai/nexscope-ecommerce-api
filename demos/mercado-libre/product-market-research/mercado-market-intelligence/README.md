# Mercado Libre Market Research

Research Mercado Libre categories, products, sales trends, and reviews.

[Official API documentation](https://www.nexscope.ai/api-docs/mercado-market-intelligence?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/mercado-market-intelligence.json)

[Repository API reference](../../../../docs/data/mercado-market-intelligence.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/mercado-libre/product-market-research/mercado-market-intelligence
node demos/clients/node/run.mjs demos/mercado-libre/product-market-research/mercado-market-intelligence
java demos/clients/java/Run.java demos/mercado-libre/product-market-research/mercado-market-intelligence
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/mercado-market-intelligence/run`.
