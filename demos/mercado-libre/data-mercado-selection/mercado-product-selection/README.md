# Mercado Product Selection API

Research Mercado Libre products, sellers, and keywords across five markets.

[Official API documentation](https://www.nexscope.ai/api-docs/mercado-product-selection?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/mercado-product-selection.json)

[Repository API reference](../../../../docs/data/mercado-product-selection.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/mercado-libre/data-mercado-selection/mercado-product-selection
node demos/clients/node/run.mjs demos/mercado-libre/data-mercado-selection/mercado-product-selection
java demos/clients/java/Run.java demos/mercado-libre/data-mercado-selection/mercado-product-selection
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/mercado-product-selection/run`.
