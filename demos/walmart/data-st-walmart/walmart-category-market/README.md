# Walmart Category Market API

Find Walmart categories and review category market reports.

[Official API documentation](https://www.nexscope.ai/api-docs/walmart-category-market?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/walmart-category-market.json)

[Repository API reference](../../../../docs/data/walmart-category-market.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/walmart/data-st-walmart/walmart-category-market
node demos/clients/node/run.mjs demos/walmart/data-st-walmart/walmart-category-market
java demos/clients/java/Run.java demos/walmart/data-st-walmart/walmart-category-market
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/walmart-category-market/run`.
