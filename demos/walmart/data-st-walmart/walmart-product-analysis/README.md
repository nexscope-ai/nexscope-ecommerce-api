# Walmart Product Analysis API

Analyze Walmart products, detail records, performance trends, and dated sales volume.

[Official API documentation](https://www.nexscope.ai/api-docs/walmart-product-analysis?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/walmart-product-analysis.json)

[Repository API reference](../../../../docs/data/walmart-product-analysis.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/walmart/data-st-walmart/walmart-product-analysis
node demos/clients/node/run.mjs demos/walmart/data-st-walmart/walmart-product-analysis
java demos/clients/java/Run.java demos/walmart/data-st-walmart/walmart-product-analysis
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/walmart-product-analysis/run`.
