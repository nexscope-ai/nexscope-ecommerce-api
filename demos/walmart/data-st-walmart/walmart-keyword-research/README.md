# Walmart Keyword Research API

Research Walmart keywords and the products associated with them.

[Official API documentation](https://www.nexscope.ai/api-docs/walmart-keyword-research?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/walmart-keyword-research.json)

[Repository API reference](../../../../docs/data/walmart-keyword-research.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/walmart/data-st-walmart/walmart-keyword-research
node demos/clients/node/run.mjs demos/walmart/data-st-walmart/walmart-keyword-research
java demos/clients/java/Run.java demos/walmart/data-st-walmart/walmart-keyword-research
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/walmart-keyword-research/run`.
