# Google AI Mode Search API

Retrieve Google AI Mode summaries for a single keyword to support research, technical questions, product selection, and market.

[Official API documentation](https://www.nexscope.ai/api-docs/google-ai-mode-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/google-ai-mode-search.json)

[Repository API reference](../../../../docs/data/google-ai-mode-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/google/data-google-tools/google-ai-mode-search
node demos/clients/node/run.mjs demos/google/data-google-tools/google-ai-mode-search
java demos/clients/java/Run.java demos/google/data-google-tools/google-ai-mode-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/google-ai-mode-search/run`.
