# Google Trends By Time API

Query Google Trends topics and trending searches by country or region for a selected time range.

[Official API documentation](https://www.nexscope.ai/api-docs/google-trends-by-time?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/google-trends-by-time.json)

[Repository API reference](../../../../docs/data/google-trends-by-time.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/google/data-google-tools/google-trends-by-time
node demos/clients/node/run.mjs demos/google/data-google-tools/google-trends-by-time
java demos/clients/java/Run.java demos/google/data-google-tools/google-trends-by-time
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/google-trends-by-time/run`.
