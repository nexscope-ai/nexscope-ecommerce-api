# Google Trends By Keywords API

Compare Google Trends search interest for multiple keywords across regions and custom time ranges for seasonal and market analysis.

[Official API documentation](https://www.nexscope.ai/api-docs/google-trends-by-keywords?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/google-trends-by-keywords.json)

[Repository API reference](../../../../docs/data/google-trends-by-keywords.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/google/data-google-tools/google-trends-by-keywords
node demos/clients/node/run.mjs demos/google/data-google-tools/google-trends-by-keywords
java demos/clients/java/Run.java demos/google/data-google-tools/google-trends-by-keywords
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/google-trends-by-keywords/run`.
