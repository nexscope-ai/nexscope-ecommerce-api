# Ozon Product Report Search API

Filter Ozon products by sales, revenue, growth, conversion, price, ratings, margin, returns, ads, seller, and fulfillment metrics.

[Official API documentation](https://www.nexscope.ai/api-docs/ozon-product-report-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/ozon-product-report-search.json)

[Repository API reference](../../../../docs/data/ozon-product-report-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/ozon/data-sr-ozon/ozon-product-report-search
node demos/clients/node/run.mjs demos/ozon/data-sr-ozon/ozon-product-report-search
java demos/clients/java/Run.java demos/ozon/data-sr-ozon/ozon-product-report-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/ozon-product-report-search/run`.
