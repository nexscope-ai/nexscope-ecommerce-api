# Ozon Market Keyword Search API

Find Ozon and Wildberries market keywords using search volume, growth, competition, pricing, sales, and conversion metrics.

[Official API documentation](https://www.nexscope.ai/api-docs/ozon-market-keyword-search?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/ozon-market-keyword-search.json)

[Repository API reference](../../../../docs/data/ozon-market-keyword-search.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/ozon/data-sr-ozon/ozon-market-keyword-search
node demos/clients/node/run.mjs demos/ozon/data-sr-ozon/ozon-market-keyword-search
java demos/clients/java/Run.java demos/ozon/data-sr-ozon/ozon-market-keyword-search
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/ozon-market-keyword-search/run`.
