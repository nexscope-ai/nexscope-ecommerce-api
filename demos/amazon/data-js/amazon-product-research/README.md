This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-js/amazon-product-research
node demos/clients/node/run.mjs demos/amazon/data-js/amazon-product-research
java demos/clients/java/Run.java demos/amazon/data-js/amazon-product-research
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-product-research/run`.
