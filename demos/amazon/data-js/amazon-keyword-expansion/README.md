# Amazon Keyword Expansion API

Find related Amazon keywords and compare search demand.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-keyword-expansion?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-keyword-expansion.json)

[Repository API reference](../../../../docs/data/amazon-keyword-expansion.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-js/amazon-keyword-expansion
node demos/clients/node/run.mjs demos/amazon/data-js/amazon-keyword-expansion
java demos/clients/java/Run.java demos/amazon/data-js/amazon-keyword-expansion
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-keyword-expansion/run`.
