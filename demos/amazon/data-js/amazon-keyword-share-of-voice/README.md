# Amazon Keyword Share Of Voice API

Compare how often brands appear in Amazon's organic and sponsored search results.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-keyword-share-of-voice?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-keyword-share-of-voice.json)

[Repository API reference](../../../../docs/data/amazon-keyword-share-of-voice.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-js/amazon-keyword-share-of-voice
node demos/clients/node/run.mjs demos/amazon/data-js/amazon-keyword-share-of-voice
java demos/clients/java/Run.java demos/amazon/data-js/amazon-keyword-share-of-voice
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-keyword-share-of-voice/run`.
