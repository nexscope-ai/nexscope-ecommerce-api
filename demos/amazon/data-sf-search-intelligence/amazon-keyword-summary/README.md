# Amazon Keyword Summary API

Compare competitor traffic from search, ads, and recommendations.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-keyword-summary?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-keyword-summary.json)

[Repository API reference](../../../../docs/data/amazon-keyword-summary.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-sf-search-intelligence/amazon-keyword-summary
node demos/clients/node/run.mjs demos/amazon/data-sf-search-intelligence/amazon-keyword-summary
java demos/clients/java/Run.java demos/amazon/data-sf-search-intelligence/amazon-keyword-summary
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-keyword-summary/run`.
