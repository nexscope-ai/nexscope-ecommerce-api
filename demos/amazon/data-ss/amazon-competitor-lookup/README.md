# Amazon Competitor Lookup API

Compare competing Amazon products by sales, price, and growth.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-competitor-lookup?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-competitor-lookup.json)

[Repository API reference](../../../../docs/data/amazon-competitor-lookup.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-ss/amazon-competitor-lookup
node demos/clients/node/run.mjs demos/amazon/data-ss/amazon-competitor-lookup
java demos/clients/java/Run.java demos/amazon/data-ss/amazon-competitor-lookup
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-competitor-lookup/run`.
