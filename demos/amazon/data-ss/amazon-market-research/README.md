# Amazon Market Research API

Assess niche size, competition, and seller concentration.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-market-research?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-market-research.json)

[Repository API reference](../../../../docs/data/amazon-market-research.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-ss/amazon-market-research
node demos/clients/node/run.mjs demos/amazon/data-ss/amazon-market-research
java demos/clients/java/Run.java demos/amazon/data-ss/amazon-market-research
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-market-research/run`.
