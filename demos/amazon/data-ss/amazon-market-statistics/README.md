# Amazon Market Statistics API

Compare sales, prices, and ratings within an Amazon category.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-market-statistics?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-market-statistics.json)

[Repository API reference](../../../../docs/data/amazon-market-statistics.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-ss/amazon-market-statistics
node demos/clients/node/run.mjs demos/amazon/data-ss/amazon-market-statistics
java demos/clients/java/Run.java demos/amazon/data-ss/amazon-market-statistics
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-market-statistics/run`.
