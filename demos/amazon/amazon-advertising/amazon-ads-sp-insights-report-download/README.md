# Amazon Ads SP Insights Report Download API

Download a completed Amazon Ads insights report from your connected advertising account and review the returned report data for further analysis.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-ads-sp-insights-report-download?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-ads-sp-insights-report-download.json)

[Repository API reference](../../../../docs/data/amazon-ads-sp-insights-report-download.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-download
node demos/clients/node/run.mjs demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-download
java demos/clients/java/Run.java demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-download
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-ads-sp-insights-report-download/run`.
