# Amazon Ads Reporting API

Create advertising reports, check their progress, and download completed reports.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-ads-reporting?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-ads-reporting.json)

[Repository API reference](../../../../docs/data/amazon-ads-reporting.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/amazon-advertising/amazon-ads-reporting
node demos/clients/node/run.mjs demos/amazon/amazon-advertising/amazon-ads-reporting
java demos/clients/java/Run.java demos/amazon/amazon-advertising/amazon-ads-reporting
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-ads-reporting/run`.
