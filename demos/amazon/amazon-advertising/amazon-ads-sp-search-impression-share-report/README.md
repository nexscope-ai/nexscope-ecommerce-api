# Amazon Ads SP Search Impression Share Report API

Request an Amazon Sponsored Products search impression share report for your chosen dates, with daily results or a period summary.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-ads-sp-search-impression-share-report?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-ads-sp-search-impression-share-report.json)

[Repository API reference](../../../../docs/data/amazon-ads-sp-search-impression-share-report.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/amazon-advertising/amazon-ads-sp-search-impression-share-report
node demos/clients/node/run.mjs demos/amazon/amazon-advertising/amazon-ads-sp-search-impression-share-report
java demos/clients/java/Run.java demos/amazon/amazon-advertising/amazon-ads-sp-search-impression-share-report
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-ads-sp-search-impression-share-report/run`.
