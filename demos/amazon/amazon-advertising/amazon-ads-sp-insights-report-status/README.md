# Amazon Ads SP Insights Report Status API

Check whether your Amazon Ads insights report is still processing or ready to download.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-ads-sp-insights-report-status?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-ads-sp-insights-report-status.json)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-status
node demos/clients/node/run.mjs demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-status
java demos/clients/java/Run.java demos/amazon/amazon-advertising/amazon-ads-sp-insights-report-status
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-ads-sp-insights-report-status/run`.
