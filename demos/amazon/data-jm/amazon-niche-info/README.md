# Amazon Niche Info API

Research demand, competition, prices, and customer reviews in an Amazon niche.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-niche-info?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-niche-info.json)

[Repository API reference](../../../../docs/data/amazon-niche-info.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-jm/amazon-niche-info
node demos/clients/node/run.mjs demos/amazon/data-jm/amazon-niche-info
java demos/clients/java/Run.java demos/amazon/data-jm/amazon-niche-info
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-niche-info/run`.
