# Amazon Policy Update Details API

Read the details of a selected Amazon policy update to understand the announcement and assess its relevance to your business.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-policy-feed-detail?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-business-insight/data-amazon-policy-feed-detail/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-business-insight/data-amazon-policy-feed-detail
node demos/clients/node/run.mjs demos/amazon/data-amazon-business-insight/data-amazon-policy-feed-detail
java demos/clients/java/Run.java demos/amazon/data-amazon-business-insight/data-amazon-policy-feed-detail
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
