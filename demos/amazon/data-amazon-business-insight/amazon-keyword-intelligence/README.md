# Amazon Keyword Intelligence API

Explore weekly Amazon Brand Analytics search-term data.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-keyword-intelligence?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-keyword-intelligence.json)

[Repository API reference](../../../../docs/data/amazon-keyword-intelligence.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-business-insight/amazon-keyword-intelligence
node demos/clients/node/run.mjs demos/amazon/data-amazon-business-insight/amazon-keyword-intelligence
java demos/clients/java/Run.java demos/amazon/data-amazon-business-insight/amazon-keyword-intelligence
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-keyword-intelligence/run`.
