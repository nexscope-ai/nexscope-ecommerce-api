# Amazon Ads Connected Stores API

List the stores connected to your Amazon Ads account so you can choose the account to use for campaign management.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-authorized-stores?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-authorized-stores/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-authorized-stores
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-authorized-stores
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-authorized-stores
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
