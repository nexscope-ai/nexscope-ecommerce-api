# Amazon Ads API Access

Connect an Amazon Ads account and check its connection status.

[Official API documentation](https://www.nexscope.ai/api-docs/amazon-ads-api-access?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/amazon-ads-api-access.json)

[Repository API reference](../../../../docs/data/amazon-ads-api-access.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/amazon-ads-api-access
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/amazon-ads-api-access
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/amazon-ads-api-access
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/amazon-ads-api-access/run`.
