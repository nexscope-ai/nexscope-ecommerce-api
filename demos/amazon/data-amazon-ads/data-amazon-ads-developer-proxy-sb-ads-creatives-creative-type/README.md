# Sponsored Brands Creatives by Format API

Work with a selected Sponsored Brands creative format to manage the content used in your advertising.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-developer-proxy-sb-ads-creatives-creative-type?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-creative-type/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-creative-type
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-creative-type
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-creative-type
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
