# Sponsored Brands Campaign List v4 API

List advertising campaigns and their settings to review the campaigns used by Sponsored Brands.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-developer-proxy-sb-v4-campaigns-list?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-campaigns-list/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-campaigns-list
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-campaigns-list
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-campaigns-list
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
