# Amazon Ads Custom Requests API

Send an allowed Amazon Ads request through your connected account when you need an advertising operation beyond the individual tools.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-developer-proxy-amazon-ads-developer-proxy?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-amazon-ads-developer-proxy/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-amazon-ads-developer-proxy
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-amazon-ads-developer-proxy
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-amazon-ads-developer-proxy
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
