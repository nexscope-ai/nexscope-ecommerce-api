# Sponsored Brands Ads by Format v4 API

Work with a selected Sponsored Brands ad format to manage the corresponding advertisements for your brand.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-developer-proxy-sb-v4-ads-ad-type?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-ads-ad-type/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-ads-ad-type
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-ads-ad-type
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-v4-ads-ad-type
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
