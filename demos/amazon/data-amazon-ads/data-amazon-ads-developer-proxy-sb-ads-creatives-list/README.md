# Sponsored Brands Ad Creative List API

List creative assets for a Sponsored Brands ad so you can review the content used in that advertisement.

[Official API documentation](https://www.nexscope.ai/api-docs/data-amazon-ads-developer-proxy-sb-ads-creatives-list?co-from=github-ecommerce-api) · [Request payload](../../../../demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-list/request.json)

This demo uses the live API Docs request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-list
node demos/clients/node/run.mjs demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-list
java demos/clients/java/Run.java demos/amazon/data-amazon-ads/data-amazon-ads-developer-proxy-sb-ads-creatives-list
```

Transport: **MCP**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/mcp`.
