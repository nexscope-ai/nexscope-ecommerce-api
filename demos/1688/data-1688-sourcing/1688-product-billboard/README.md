This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/1688/data-1688-sourcing/1688-product-billboard
node demos/clients/node/run.mjs demos/1688/data-1688-sourcing/1688-product-billboard
java demos/clients/java/Run.java demos/1688/data-1688-sourcing/1688-product-billboard
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/api/skill-api/v1/skills/1688-product-billboard/run`.
