# WooCommerce Product Attribute Detail API

Look up a specific public product attribute in a WooCommerce store by its ID.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-attribute-detail?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-attribute-detail.json)

[Repository API reference](../../../../docs/data/woocommerce-product-attribute-detail.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-attribute-detail
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-attribute-detail
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-attribute-detail
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productAttributeDetail`.
