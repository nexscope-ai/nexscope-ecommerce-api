# WooCommerce Product Attribute Terms API

Explore the public values for a WooCommerce product attribute, such as colors or sizes listed by a store, using the chosen attribute ID.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-attribute-terms?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-attribute-terms.json)

[Repository API reference](../../../../docs/data/woocommerce-product-attribute-terms.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-attribute-terms
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-attribute-terms
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-attribute-terms
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productAttributeTerms`.
