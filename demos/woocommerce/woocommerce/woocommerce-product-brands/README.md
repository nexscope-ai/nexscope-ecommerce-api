# WooCommerce Product Brands API

Browse or search the public brands in a WooCommerce store.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-brands?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-brands.json)

[Repository API reference](../../../../docs/data/woocommerce-product-brands.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-brands
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-brands
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-brands
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productBrands`.
