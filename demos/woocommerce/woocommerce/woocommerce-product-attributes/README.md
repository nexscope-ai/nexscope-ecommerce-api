# WooCommerce Product Attributes API

Browse the public product attributes available in a WooCommerce store, such as color and size, to understand how its products are organized.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-attributes?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-attributes.json)

[Repository API reference](../../../../docs/data/woocommerce-product-attributes.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-attributes
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-attributes
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-attributes
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productAttributes`.
