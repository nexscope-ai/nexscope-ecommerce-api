# WooCommerce Product Categories API

Explore a WooCommerce store’s public product categories.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-categories?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-categories.json)

[Repository API reference](../../../../docs/data/woocommerce-product-categories.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-categories
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-categories
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-categories
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productCategories`.
