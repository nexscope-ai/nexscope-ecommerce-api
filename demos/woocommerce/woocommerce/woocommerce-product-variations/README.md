# WooCommerce Product Variations API

Explore the public variations of a WooCommerce product, such as different sizes or colors, using its store address and product ID.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-variations?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-variations.json)

[Repository API reference](../../../../docs/data/woocommerce-product-variations.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-variations
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-variations
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-variations
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productVariations`.
