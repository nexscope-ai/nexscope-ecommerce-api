# WooCommerce Product Tags API

Browse or search the public product tags in a WooCommerce store.

[Official API documentation](https://www.nexscope.ai/api-docs/woocommerce-product-tags?co-from=github-ecommerce-api) · [Request payload](../../../../payloads/woocommerce-product-tags.json)

[Repository API reference](../../../../docs/data/woocommerce-product-tags.md)

This demo uses the repository catalog request and endpoint. Review the payload and replace sample identifiers with valid inputs.
Commands preview the request. Add `--execute` only when you intend to send it; calls may consume credits or change account data.

Run from the repository root:

```bash
python demos/clients/python/run.py demos/woocommerce/woocommerce/woocommerce-product-tags
node demos/clients/node/run.mjs demos/woocommerce/woocommerce/woocommerce-product-tags
java demos/clients/java/Run.java demos/woocommerce/woocommerce/woocommerce-product-tags
```

Transport: **REST**. Endpoint: `https://api.nexscope.ai/woocommerce/productTags`.
